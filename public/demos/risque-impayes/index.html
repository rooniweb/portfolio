Méthode et limites

  • Cible : facture non soldée 60 jours après l'échéance. Une ligne par facture, ~100 000 factures de 5 000 comptes.
  • Sans fuite : chaque variable est calculée à la date d'émission, avec ce qu'on savait ce jour-là.
  • Découpage temporel : apprentissage sur 2024-2025, validation puis test sur des mois jamais vus.
  • Oracle : la vraie probabilité du simulateur donne le plafond atteignable ; l'écart restant vient de difficultés soudaines qu'aucun historique de paiement n'annonce.
  • À mesurer : l'efficacité d'une relance (35 % ici) est une hypothèse ; elle se mesure par un test A/B avec groupe témoin.
  • Éthique : aucune variable sensible (âge, sexe, quartier) ; le score oriente les relances, il ne déclenche aucune action automatique.
Projet de démonstration : données simulées par un générateur à graine fixe, entièrement reproductible (notebook et scripts fournis).
